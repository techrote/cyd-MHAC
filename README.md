# CYD-MHAC

Experimental standalone audiovisual synthesizer for the classic ESP32-2432S028R. Audio/platform and visual/XY workers collaborate through a versioned control contract. Research authority: https://github.com/techrote/MachineHumanAudioCybersemiotics; hardware reference: https://github.com/techrote/cyd-diviner. No repository-wide license declared. Work in issue-scoped draft PRs; no hardware qualification or flash approval implied. The audio worker owns platform bootstrap and shared contract; the visual worker owns rendering and touch UI.
