## Additive contract for visual lane

`feature_version=1`, `feature_window=128`; existing packed analysis, control, patch constants, legacy snapshot and watchdog untouched. UI can keep a local `mhac::AudioFeatures latest{};` and call `mhac::exchange.features.read(latest)` once per frame or UI tick. False leaves the previous snapshot intact, including before first complete window. True can repeat a snapshot: compare sample_end for freshness. No audio lock/wait, no reader spinning. Latest-value mailbox, not an event queue; UI may skip windows. One audio producer, bounded one-attempt read, all five words atomic and sequentially consistent. Sequence wrap ABA requires 2^31 full publications during one read; no guarantee for arbitrarily suspended readers. Sample clock wraps modulo 2^32 (about 49.7 hours at 24kHz); compare unsigned elapsed samples. Timestamp is exclusive end of rendered samples, NOT wall-clock time, DAC presentation or proof of DMA delivery.

Windows are independent of render partition: 128 samples, 5.333 ms at 24 kHz. Measurements use actual signed PCM16 output after the gate envelope, prior to the DAC quantization. peak (max absolute PCM), mean_abs (floor average absolute PCM), mean_delta (floor mean absolute first difference, including preceding window's last sample), onset (positive change in mean_abs since previous window), crossings (sign changes ignoring zero, carries last nonzero sign across windows). Initial previous sample/mean/sign zero. Native engine gain cap 8191, generic accumulator handles -32768/+32767. Mean delta is an activity/brightness proxy, not a measured frequency band; onset is a simple amplitude rise, not an event detector or semantic/perceptual inference. The analysis is read-only for UI; it must never drive gate heartbeat. A paused rendering/audio task leaves last snapshot stale. Audio features are measured, subsequent artwork an artistic mapping.
