## DSP
Erasure Pulse: free-running 500 ms four-onset motif at nominal sample offsets 0, 2832, 7416, 10248, smoothed 1100-sample target windows, X pitch and Y continuously attenuates onset two and partially attenuates four; Y also retains the phase morph timbre. Not the Golden Receipt mathematical affine-normalization protocol: creative exaptation only, no human-perception claim.
Recursive Echo: 1536-sample (64 ms) fixed mono signed-16 delay; carrier input gain .35, feedback .20–.60, Y wet mix 0–.65. Bound on internal delay magnitude .35/(1-.60)=.875 plus quantization towards zero, below representable amplitude; output convex blend bounded by full-scale carrier. No external memory or allocations; inactive/fully silent state lazily invalidates history without clearing an array in render. Ordinary release and watchdog retain existing post-effect envelope; fully silent output does not imply physical DAC silence. Delay is a short comb/echo, not an independent polyphonic voice or long ambience effect. Both new patches join existing 256-sample simplex transition. Native Engine sizeof 3160 bytes vs 64, +3096 bytes (3072 bytes delay storage); not a device RAM measurement.
